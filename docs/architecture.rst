Architecture
============

The architecture document lives in Markdown under :file:`docs/architecture.md`
(rendered with diagrams on the project's Git forge). It describes the system
as it stands approaching v1.0.0 — the guiding principles, crate layout, state
model, window/workspace/output handling, the input and render paths, the
protocol surface and its capability gating, and the design decisions with the
reasoning behind them.

(A future revision of this guide may translate it into RST in-place.)
